# 功能更新

## 2026-10-22 崩溃弹窗改为始终提示（未知原因展示日志末尾）

**需求**：无论游戏崩溃后日志能否分析出明显问题，都要弹窗；未知原因也要展示相关日志段落；删掉旧的「游戏进程发生错误」窗口。

**改动**（`playerloganalyzer.{h,cpp}` / `mainwindow.{h,cpp}` / `pages/settingspage.cpp`）：
- `analyzePlayerLog` 对 `NoCrash` 填充 `context` 为日志末尾 40 行（新增 `lastLines`），供未知原因弹窗展示；识别出崩溃类型时仍按「关键错误前溯 40 行」规则提取。
- `onGameFinished` 不再单独要求 `exitCode != 0`：`maybeShowCrashAnalysis(exitCode)` 内先分析，退出码非 0 或日志含崩溃痕迹即弹窗，退出码 0 且无崩溃痕迹才静默返回。新增「游戏异常退出」与「游戏异常退出（未识别出明确原因）」两种兜底文案（含退出码），`Player.log` 缺失时也提示可能原因。
- 弹窗底部「打开日志文件 / 保存日志」仅在日志存在时提供；上下文为空时显示「（日志为空或无法读取）」。
- `onGameError` 删除原「游戏进程发生错误。」弹窗，只保留状态复位与窗口恢复（启动失败仍由 `onLaunchClicked` 的「启动游戏失败。」提示）。
- 设置页开关 tooltip 改为「始终弹窗展示原因与日志段落」的描述。

**翻译改动**：`lupdate` 新增 6 条，en_US 全部补译并 `lrelease` 重建（639 条，638 finished、1 条既有 `恢复前` 遗留 unfinished），zh_CN 新增保持 unfinished 同文；旧 `游戏进程发生错误。`、`（未提取到关键错误上下文）` 等标记为 vanished。

**验证**：Qt 6.12.0 mingw 编译链接通过；`test_launcher` 新增 1 例（NoCrash 仍返回末尾 40 行上下文），ctest 通过。

## 2026-10-22 崩溃分析新增「加载时原生内存溢出」识别

**需求**：给游戏崩溃日志分析增加这类报错——Player.log 在 "Load xxx" 之后突然以 Unity 原生崩溃转储（Crash!!!）退出、且 Mono 端没有抛异常时，基本可判定为游戏加载时的原生内存溢出（这些加载操作不走 Mono 栈），个别情况是模组资源损坏。

**启动器改动**（`playerloganalyzer.{h,cpp}` / `mainwindow.cpp` / `pages/settingspage.cpp`）：
- `PlayerLogAnalysis::Kind` 新增 `NativeLoadOutOfMemory`，并新增 `loadHint` 字段（崩溃前最后一条有效日志行）。判定三条件：日志含 "Crash!!!" 且其后有 "OUTPUTTING STACK TRACE"（`locateCrashDumpOffset`，取最后一次出现）→ 崩溃前最后一条非空、非 `(Filename: ...)` 行匹配 `^\s*load\w*`（`isLoadLogLine`）→ 其前 40 行内没有 `Exception` / `Unhandled exception`（`hasManagedExceptionBefore`）。任一不满足则回落到既有 OOM / `Caught fatal signal` 判定。
- 上下文提取复用既有的 40 行回溯（`locateErrorOffset` 对该 kind 定位到崩溃转储首行）；`extractPlayerLogContext` 改为直接复用 `analyzePlayerLog` 的判定结果，删掉重复的检测分支。
- 弹窗新增分支：标题「游戏在加载资源时崩溃（疑似原生内存不足）」，正文显示 `loadHint`（如 `Load MBM texture: KFC/parts/...`），说明贴图/模型解压上传走引擎原生代码、不经 Mono 栈，并分别给出「内存不足」与「模组资源损坏」的建议。
- 设置页崩溃分析开关 tooltip 补充该类检测说明。

**翻译改动**：`lupdate` 新增 9 条（本功能 3 条 + 此前遗漏的 PhysicsRangeExtender 6 条），en_US 全部补译并 `lrelease` 重建（636 条，635 finished，1 条既有 `恢复前` 遗留 unfinished），zh_CN 新增条目保持 unfinished 同文（运行时回退中文源文），dist/translations 已同步 `.qm`。

**验证**：Qt 6.12.0 mingw 编译链接通过；`test_launcher` 新增 3 例（真实样本识别、崩溃前有托管异常时不判为该类、无 Load 行时不判为该类），ctest `test_launcher` 通过。
