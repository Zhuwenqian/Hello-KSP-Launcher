# 功能更新

## 2026-08-12：半透明 UI 与自定义背景图

- 整体 UI 改为半透明风格：边栏、启动栏、内容卡片（实例项/设置分组/列表等）均使用 rgba 半透明背景
- 边栏透明度约 65%，卡片透明度约 75%，输入框与按钮保持不透明以保证可读性
- 主窗口底层新增 QLabel 背景层，显示当前背景图（Cover 模式：保持比例填充，超出裁剪）
- 跟随窗口缩放自动重绘背景图
- 浅色/深色主题均支持半透明与背景图

### 背景图片管理

- 新增 `BackgroundManager` 单例（src/backgroundmanager），负责加载、缓存、切换背景
- 默认背景打包在资源中：`resources/backgrounds/default.png`（来自 `Kerbal Space Program BG2.png`）
- 用户可在「启动器设置 → 背景图片」中选择本地图片替换背景，支持 PNG / JPG / JPEG
- 用户选中的图片会被复制到 `<appDir>/backgrounds/user_bg_<uuid>.<ext>`，避免原文件被移动/删除后失效
- 设置项 `backgroundPath` 持久化到 HKSPL.json，下次启动自动恢复
- 提供"重置为默认"按钮，一键回到默认背景
- 设置面板含 140px 高度缩略图预览 + 当前路径显示

### 相关文件变更

- `src/backgroundmanager.h/.cpp` 新增
- `src/configmanager.h/.cpp` 新增 `backgroundPath` 字段及 getter/setter
- `src/mainwindow.h/.cpp` 新增 `m_backgroundLabel`/`m_contentContainer`，重写 `resizeEvent`/`changeEvent`
- `src/pages/settingspage.h/.cpp` 新增「背景图片」分组 UI
- `src/pages/homepage.cpp` 改用 `state` 动态属性 + QSS 状态选择器，避免 setStyleSheet 覆盖主题
- `resources/themes/dark.qss` / `light.qss` 全面重写为半透明
- `resources/resources.qrc` 引入 `backgrounds/default.png`
- `CMakeLists.txt` 编译新源文件

## 2026-08-12：导出整合包功能

- 在实例管理侧边栏底部新增"导出整合包"按钮
- 点击后弹出文件保存对话框，默认路径为启动器根目录，默认文件名为`实例名.zip`
- 使用 miniz 库将 GameData 目录打包为 zip，包含 GameData 层级
- 排除项（仅 GameData 根目录）：
  - Squad 文件夹
  - SquadExpansion 文件夹
  - ModuleManager.ConfigCache 文件
  - ModuleManager.ConfigSHA 文件
  - ModuleManager.Physics 文件
  - ModuleManager.TechTree 文件
- 包含空文件夹
- 支持 QProgressDialog 进度条显示，可取消

## 2026-08-12：Bool值改为开关控件

- 新增自定义 ToggleSwitch 开关控件（src/widgets/toggleswitch），深色轨道+浅色圆钮，带平滑动画
- 游戏设置界面（instancedetailpage.cpp）：bool 类型设置项从 QComboBox 下拉框改为 ToggleSwitch 开关
- Kerbals 管理界面（savedetailpage.cpp）：badS/veteran/hero 布尔属性从 QComboBox 下拉框改为 ToggleSwitch 开关
- 开关切换时自动提交数据，无需额外确认
