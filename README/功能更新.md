# 功能更新

## 2026-08-14：GameData DLL 扫描 + KSP 版本兼容检查

- **手动模组识别（AD）**：打开实例时扫描 `GameData` 下所有 `.dll`（排除 `Squad`、`SquadExpansion` 官方目录），以 DLL 文件名第一个 `.` 之前的部分作为标识符，识别手动安装的模组。
  - 实现：`GameInstance::scanUnmanagedDlls()`（`gameinstance.h/.cpp`），`CKanManager::scanUnmanagedDlls/isAutoDetected`。
- **AD 状态展示**：手动安装模组在表格中状态显示为 `AD`，复选框禁用，安装/卸载/升级按钮均不可用（`modtablemodel`、`instancedetailpage.cpp` 的 `updateModActionButtons`）。
- **KSP 版本兼容检查**：兼容门槛固定为中版本规则——模组 `ksp_version` 的中版本 ≥ 9（即 1.9.0）视为兼容，< 9 不兼容；未声明或非法 `ksp_version` 视为兼容。
  - 实现：`CkanModule::isCompatible()`（`ckanmodule.cpp`，常量 `kCompatibleMinMinor = 9`）。
- **不兼容模组过滤**：不兼容模组默认隐藏，模组管理页顶栏新增「显示不兼容」开关，勾选状态持久化到 `HKSPL.json` 的 `showIncompatibleMods`（`ConfigManager`、`ModsFilterProxyModel::filterAcceptsRow`）。
- **单测**：新增 `TestGameInstance`（官方目录排除、多文件去重、无 GameData 返回空），重写 `TestCkanModule::compatible` 以匹配固定中版本门槛规则（`tests/test_libckan.cpp`）。

## 2026-08-14：registry.json 补全必填字段（官方 CKAN 兼容）

- 用官方 CKAN 打开实例时报「缺少必填字段 license」，根因是 `CkanModule::toJsonObject()` 只序列化了 6 个字段，落到 `registry.json` 的 `source_module` 里缺少 `license` 等官方必填字段。
- 将 `CkanModule::toJsonObject()` 改为与 `fromJsonObject()` 完整对应的往返序列化，补齐 `license`、`author`、`ksp_version`、`download`、`download_hash`、`resources`、依赖关系、安装规则等全部元数据，`provides` 按 CKAN 原格式输出为标识符字符串列表。
- 新增 `Relationship::toJsonObject()`（还原 name + version 约束）与 `ModuleInstallDescriptor::toJsonObject()`，供上述序列化使用。
- 涉及文件：`src/ckan/ckanmodule.cpp`、`src/ckan/relationship.h/.cpp`、`src/ckan/moduleinstalldescriptor.h/.cpp`
- 新增 `TestRegistry::licenseRoundtrip` 单测：验证注册表序列化后 license/author/ksp_version 完整保留（`tests/test_libckan.cpp`）

## 2026-08-14：索引获取与模组下载的进度条 / 超时 / 取消

- **进度条**：模组下载与仓库索引获取均接入进度条（位于模组管理页下载框区域）。模组按批量总字节数聚合进度，并显示已下载大小与实时速度；索引 tar.gz 因总量未知，进度条呈不确定态。
- **超时机制**：HTTP 连接建立与传输空闲均由 `setTransferTimeout(30s)` 统一兜底（Qt 的 transferTimeout 每次收包都会重置，等同 30s 连接 + 30s 空闲超时）。
- **取消支持**：下载线程通过 `std::atomic_bool` 轮询取消标志，用户点「取消」即中止当前下载；取消索引或模组下载均不弹错误框，已下载的临时数据不写入缓存。
- **接入面**
  - `Downloader::downloadProgressed`：新增进度回调 / 超时 / 取消（`downloader.h/.cpp`）
  - `ModuleInstaller::install`：聚合批量总进度，`byteProgress` 信号携带已下载字节 / 总量 / 速度（`moduleinstaller.h/.cpp`）
  - `RepoIndex::build/buildCached` 与 `CKan::refreshIndex`：透传进度回调与取消标志（`repoindex.h/.cpp`、`ckan.h/.cpp`）
  - `CKanManager`：冒泡 `downloadProgress` 信号，`cancelCurrentOperation()` 同时取消索引与安装（`ckanmanager.h/.cpp`）
  - `InstanceDetailPage`：进度条 + 大小/速度标签 + 取消按钮，索引刷新与安装/升级共用（`instancedetailpage.h/.cpp`）
- 新增 `TestDownloader` 单测：本地文件验证进度回调与取消标志路径（`tests/test_libckan.cpp`）

## 2026-08-14：CKAN 下载健壮性 + 仓库索引缓存

- **下载健壮性**：下载器支持内容校验（`Downloader::Validator`），模块下载会校验是否为 ZIP 归档，非预期内容（错误页/被截断）视为失败并自动重试镜像；下载前校验缓存有效性，损坏缓存自动删除重下；错误信息更明确（区分网络错误与内容校验失败）。zip 打开改用内存读取（`mz_zip_reader_init_mem`），规避 Windows fopen 的 ANSI 路径编码问题。
- **仓库索引缓存**：新增 `RepoIndex::setCacheDir` / `buildCached`，将 CKAN-meta 的 tar.gz 落盘到 `exe目录/ckan_cache/index/`，默认有效期 6 小时。进入模组页自动加载时优先用缓存（不再每次启动都下载）；点「刷新仓库」则强制重新下载（`refreshIndexAsync(true)`）。
- 涉及文件：`downloader.h/.cpp`、`moduleinstaller.cpp`、`repoindex.h/.cpp`、`ckan.h/.cpp`、`ckanmanager.h/.cpp`、`pages/instancedetailpage.cpp`

## 2026-08-14：内置 CKAN 模组管理（libckan）

- 新增 `libckan` 静态库（`src/ckan/`），用 C++ 重写 CKAN 核心，数据库（CKAN-meta 仓库）与 registry.json 格式完全兼容官方版本
- 保留独立接口（`ckan::CKan` 等类），供启动器后续接入更多功能

### 核心逻辑

- `version`：`ModuleVersion` / `GameVersion`，实现与官方 CKAN 一致的语义化版本比较（含 epoch、build 忽略规则）
- `ckanmodule`：模块元数据 `CkanModule` 的 JSON 解析/序列化，缺失 identifier 或 version 判定为无效
- `relationship`：依赖/推荐/冲突/提供关系描述符及版本约束判定
- `moduleinstalldescriptor`：安装规则（file/find/find_regexp）解析、文件筛选与路径转换（GameData/GameRoot/Ships 等）
- `registry`：registry.json 读写，`installed_modules` / `installed_files` / `sorted_repositories` 完整兼容
- `relationshipresolver`：BFS 依赖展开，支持 depends/recommends/conflicts/provides，虚拟包索引解析，自动选择满足约束的最高版本
- `repoindex`：解析 CKAN-meta tar.gz，构建 标识符→多版本 仓库索引
- `downloader` / `moduleinstaller`：HTTP 下载（含镜像/代理）、miniz 解压、安装/卸载与文件归属跟踪
- `gameinstance` / `ckan`：实例生命周期封装与对外统一入口

### 界面与接入

- `CKanManager` 单例（`src/ckanmanager`）：封装 libckan，提供异步刷新索引/安装/卸载/升级，供 UI 调用
- 实例管理页「模组」标签页重构为完整模组管理界面：搜索、状态筛选、详情、安装/卸载/升级，`QTableView`+`ModsTableModel`+过滤代理模型
- 所有新文案均已 `tr()` 包裹，纳入 zh_CN / en_US 双语翻译

### 单元测试

- 新增 `tests/test_libckan.cpp`（QtTest），覆盖版本比较、安装规则、registry、依赖解析、虚拟包、冲突、缺失依赖等 44 个用例
- `CMakeLists.txt` 新增 `test_libckan` 目标，`enable_testing()` + `add_test` 接入 CTest

### 相关文件变更

- 新增 `src/ckan/*`（13个源文件）、`src/ckanmanager.h/.cpp`、`src/pages/modtablemodel.h/.cpp`、`tests/test_libckan.cpp`
