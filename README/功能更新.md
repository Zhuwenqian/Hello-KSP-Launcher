# Hello KSP Launcher 功能更新记录

## v1.0.6 - 存档备份功能 (2026-08-12)

### 新增功能
1. **存档备份管理**
   - 在存档详情页侧边栏新增「备份管理」标签
   - 备份存储结构：启动器目录/backups/存档名/存档名_yyyyMMdd_HHmmss.zip
   - 按存档名分子目录存放，避免备份文件混乱
   - 文件名使用时间戳命名，防止重名冲突

2. **创建备份**
   - 顶部「创建新备份」按钮，点击后压缩当前存档文件夹
   - 使用高性能miniz ZIP压缩库（MZ_BEST_SPEED模式平衡速度与压缩率）
   - 备份前检查存档目录是否存在或为空，空目录/不存在时提示用户
   - 进度对话框实时显示压缩进度（0-100%），后台线程执行不阻塞UI
   - 备份失败自动清理临时文件

3. **备份列表管理**
   - 自动扫描对应存档目录的备份文件，按时间倒序排列
   - 每个备份项显示：存档名称、备份时间（yyyy年MM月dd日 HH:mm:ss）
   - 空列表时显示「（暂无备份）」提示
   - 顶部「刷新」按钮手动刷新备份列表

4. **备份操作**
   - 文件夹图标按钮：在Windows文件资源管理器中定位并选中该备份文件
   - 垃圾桶图标按钮：删除备份（二次确认弹窗）
   - 删除失败提示（文件被占用等情况）

5. **技术实现**
   - 集成miniz v3.1.2高性能ZIP压缩库（public domain，C语言实现，秒级压缩几十GB大文件）
   - 使用QtConcurrent在后台线程执行压缩，避免UI卡顿
   - 通过QMetaObject::invokeMethod从工作线程安全更新UI进度
   - 递归遍历目录添加到ZIP，保持原始目录结构，压缩级别MZ_DEFAULT_LEVEL
   - 为未来整合包导出功能预留高性能压缩基础

6. **修复：中文存档名无法备份**
   - 根因：miniz的mz_zip_writer_init_file内部使用fopen按ANSI代码页解析路径，系统代码页为UTF-8/英文时打不开中文路径
   - 修复：改用QFile作为写入后端（QFile使用Unicode路径，跨代码页均正常），通过miniz自定义m_pWrite回调+ m_pIO_opaque将压缩数据写入QFile
   - 中文存档目录和中文备份文件名均支持

### 文件变更
- 新增：thirdparty/miniz.c/miniz.h（miniz v3.1.2单文件ZIP压缩库）
- 修改：instancemanager.h/cpp（新增BackupInfo结构体+getBackupsRootDir/getBackupDirForSave/listBackups/createBackup/deleteBackup/revealBackupInExplorer方法）
- 修改：pages/savedetailpage.h/cpp（新增备份管理UI+setupBackupsTab/refreshBackupList+相关槽函数）
- 修改：CMakeLists.txt（启用C语言支持+添加miniz源文件+Qt6::Concurrent模块）
- 修改：resources/resources.qrc（新增refresh.svg/trash-2.svg图标）
- 修改：resources/themes/dark.qss/light.qss（新增iconButton样式）

## v1.0.5 - 存档管理与Kerbal编辑 (2026-08-12)

### 新增功能
1. **存档管理入口**
   - 在实例管理页面侧边栏「高级」上方新增「存档管理」按钮
   - 点击进入存档列表页，自动扫描游戏根目录/saves文件夹
   - 自动排除DarkMultiPlayer、scenarios、training特殊文件夹
   - 存档列表项显示：存档名称、版本号、游戏模式、模组状态

2. **存档信息查看（只读）**
   - 存档详情页全屏覆盖式展示（类似HMCL世界管理界面）
   - 顶部导航：返回按钮（回存档列表）+ 首页按钮（回启动器首页）
   - 侧边栏：存档信息、管理Kerbals 两个标签
   - 存档信息展示项：存档标题、游戏版本、游戏模式（沙盒/生涯/科学）、种子、有模组、完整版本号、创建版本、时间戳、环境信息

3. **Kerbal管理功能**
   - 列出存档中所有Kerbal人员，显示姓名、性别、类型、职业、状态标签（老兵/英雄/坏蛋）
   - 点击Kerbal项进入详情编辑页
   - 可编辑属性：姓名（文本编辑）、性别（Male/Female下拉框）、职业（飞行员/工程师/科学家等）、勇敢度（0.0-1.0浮点数值）、愚蠢度（0.0-1.0浮点数值）、坏蛋（True/False下拉框）、老兵（True/False下拉框）、英雄（True/False下拉框）
   - 类型为只读不可编辑
   - 数值输入使用QDoubleSpinBox限制范围0.0-1.0，步长0.1
   - 返回列表时提示放弃未保存修改
   - 保存按钮带括号匹配验证，防止SFS存档格式损坏
   - 使用originalName字段定位Kerbal，支持修改姓名后正确保存
   - 增大存档列表项（80px）和Kerbal列表项（70px）高度，字体加大，间距更舒适

4. **SFS文件解析与写回**
   - 实现KSP persistent.sfs存档格式解析（大括号嵌套树形结构）
   - 正确解析GAME块顶层元数据和ROSTER/KERBAL块人员数据
   - 保存时保持原文件缩进格式，仅修改目标字段值
   - 保存前后进行大括号计数匹配验证，不匹配则拒绝写入

### 文件变更
- 修改：instancemanager.h/cpp（新增SaveInfo/KerbalInfo结构体+listSaves/loadSaveInfo/loadKerbals/saveKerbals方法，KerbalInfo增加originalName字段支持改名）
- 新增：src/pages/saveslistpage.h/cpp（存档列表页）
- 新增：src/pages/savedetailpage.h/cpp（存档详情页+Kerbal编辑）
- 修改：pages/instancedetailpage.h/cpp（添加存档管理导航按钮）
- 修改：mainwindow.h/cpp（集成新页面导航逻辑）
- 修改：CMakeLists.txt（添加新源文件）
- 修改：resources/themes/dark.qss/light.qss（深色模式导航/返回按钮文字图标改为白色，统一设置icon-size，新增primaryButton样式）

## v1.0.4 - 高级启动参数 (2026-08-12)

### 新增功能
1. **高级启动参数设置**
   - 在实例管理页面侧边栏新增「高级」标签页
   - 提供启动参数输入框，可输入如 `-force-d3d11`、`-popupwindow` 等KSP命令行参数

   - 点击「确认保存」按钮将参数保存到该实例配置
   - 再次点击输入框可随时修改，保存后立即生效
   - 参数持久化存储在HKSPL.json中，每个实例独立保存

2. **启动游戏时传递参数**
   - 修改InstanceManager::launchGame支持附加参数
   - 首页点击启动游戏自动使用该实例配置的启动参数
   - 使用QProcess::splitCommand正确解析参数，兼容带空格引号的参数

### 文件变更
- 修改：configmanager.h/cpp（KSPInstance加launchArgs字段+序列化+update方法）

- 修改：mainwindow.cpp（启动时传递launchArgs）
