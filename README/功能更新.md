# Hello KSP Launcher 功能更新记录

## v1.0.3 - 界面重构与编辑修复 (2026-08-12)

### 修复问题
1. **设置值无法编辑问题**
   - 问题：设置NoEditTriggers后editItem()也无法触发编辑
   - 修复：自定义QStyledItemDelegate委托类精确控制
   - 委托createEditor中：非第1列（值列）直接返回nullptr禁止编辑
   - 移除手动itemDoubleClicked信号处理，使用Qt标准编辑机制

2. **Bool类型值编辑优化**
   - True/False值双击后弹出下拉选择框（QComboBox）
   - 选项：True / False，避免手动输入错误
   - 委托自动识别值是否为布尔类型，选择对应编辑器

### 界面重构
3. **新增首页(HomePage)**
   - 启动器打开默认进入首页
   - 显示当前选中实例名称、路径、状态摘要
   - 状态摘要：路径有效性、已安装DLC数量、模组数量
   - 有效路径显示蓝色高亮框，无效路径显示橙色警告框

4. **启动栏显示逻辑改进**
   - 启动游戏按钮仅在**首页**显示
   - 进入实例列表、实例管理、启动器设置页面时自动隐藏启动栏
   - 返回首页时自动显示启动栏，符合HMCL交互逻辑

5. **导航栏更新**
   - 新增"首页"按钮（home图标）
   - 按钮顺序：首页 → 实例管理 → 实例列表 → 启动器设置
   - 当前页按钮高亮状态正确同步

6. **页面返回导航完善**
   - 实例列表页面顶部添加返回按钮（左箭头图标+"返回"）
   - 点击返回按钮回到首页并显示启动栏
   - 实例详情页返回按钮：返回实例列表页（保持启动栏隐藏）
   - 所有页面导航路径完整闭环

7. **新增2个SVG图标**
   - home.svg：首页图标（房子形状）
   - arrow-left.svg：左箭头返回图标
   - _gen_icons.py同步更新

### 文件变更
- 新增：src/pages/homepage.h / homepage.cpp
- 修改：src/mainwindow.h/cpp（导航逻辑+启动栏显隐）
- 修改：src/pages/instancelistpage.h/cpp（添加返回按钮）
- 修改：src/pages/instancedetailpage.cpp（自定义委托编辑）
- 修改：CMakeLists.txt（添加homepage）
- 修改：resources/resources.qrc（添加新图标）

## v1.0.2 - 设置页面改进 (2026-08-12)

### 修复问题
1. **设置项键名不可编辑**
   - 键名列（第0列）完全锁定，仅值列（第1列）可通过双击编辑
   - 使用 itemDoubleClicked 信号精确控制只允许编辑第1列
   - 分类父节点不可编辑

2. **DLC只显示英文**
   - 移除DLC中文名称翻译，直接使用原始英文名
   - 状态改为英文：Installed / Not Installed

### 功能增强
3. **设置项分类显示**
   - 树形结构按分类分组
   - 分类父节点显示加粗标题 + 包含项数，默认展开

4. **补充全部设置项翻译**
   - 从约50项扩展到200+项翻译覆盖
   - GameSetting结构体新增category字段
