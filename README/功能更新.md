# Hello KSP Launcher 功能更新记录

## v1.0.1 - Bug修复与功能增强 (2026-08-12)

### 修复问题
1. **修复实例切换崩溃问题**
   - 问题：点击未选中实例 → 返回 → 点击另一实例时程序崩溃
   - 原因：信号处理中直接删除发送信号的widget导致野指针
   - 修复：使用 QTimer::singleShot 延迟刷新 + deleteLater 安全删除对象
   - 添加重入保护标志防止重复刷新

2. **修复DLC项目显示宽度问题**
   - DLC列表项高度不足50px，文字显示不全
   - 增大边距和固定高度，确保内容完整展示
   - 状态标签添加最小宽度保证对齐

### 功能增强
3. **游戏设置页面改进**
   - 隐藏 SETTINGS_FILE_VERSION 内部版本字段
   - 设置键名自动翻译成中文易读名称（常见KSP设置项均已覆盖）
   - 设置值列支持直接双击编辑修改
   - 添加"保存设置"按钮，修改后可写回 settings.cfg
   - 保存功能保留原文件格式和注释，只更新键值
   - 保存成功/失败有明确提示

4. **集成Lucide风格SVG图标系统**
   - 添加19个SVG图标（全部基于Lucide设计规范）
   - 所有按钮图标使用矢量SVG，支持任意缩放不模糊
   - 图标颜色自动适配主题前景色（currentColor）
   - CMake添加Qt6::Svg模块支持SVG渲染
   - 图标清单：
     - 导航栏：实例管理(database)、实例列表(list)、设置(settings)
     - 详情页：返回(back)、游戏设置(sliders)、DLC(package)、模组(puzzle)、保存(save)
     - 启动栏：火箭启动(rocket)、停止(stop)、下拉切换(chevron-down)
     - 其他：添加实例(add)、更多菜单(more-vertical)、月亮/太阳(moon/sun)、地球(globe)等

5. **DLC名称中文化**
   - Making History → "历史扩展包 (Making History)"
   - Breaking Ground → "地面扩展包 (Breaking Ground)"
   - 状态指示器改进：● 已安装 / ○ 未安装

### 构建改进
6. **输出目录改为dist/**
   - CMake配置可执行文件输出到项目根目录/dist
   - windeployqt 部署所有依赖到dist目录
   - dist目录为完整可分发的程序目录

### 按钮优化
7. - 移除所有emoji/特殊Unicode符号，统一使用SVG图标
   - 返回按钮从"←"改为带箭头图标+"返回"文字
   - 更多菜单从"⋮"改为"..."
   - 实例切换从"▲"改为纯图标下拉按钮

## v1.0.0 - 初始版本 (2026-08-12)

### 功能完成情况
1. **项目基础架构**
   - C++ Qt6 高性能实现，资源占用少
   - CMake构建系统，支持跨平台编译
   - 深色/浅色双主题QSS样式

2. **配置管理**
   - HKSPL.json配置文件持久化
   - 启动器设置：语言、启动后行为、主题
   - 实例CRUD管理：添加、删除、重命名
   - 当前实例选中状态保存

3. **HMCL风格界面布局**
   - 左侧导航栏 + 右侧内容区 + 底部启动栏
   - 导航分区：游戏（实例管理、实例列表）、通用（启动器设置）

4. **实例列表**
   - 卡片式列表，复选框单选
   - 添加实例：浏览选择KSP exe
   - 重命名/删除实例（不修改游戏文件）
   - 点击实例进入详情管理

5. **实例详情**
   - 二级侧边栏导航：游戏设置/DLC/模组管理
   - 游戏设置：读取settings.cfg
   - DLC检测：Making History、Breaking Ground
   - 模组列表：扫描GameData目录

6. **启动器设置**
   - 语言选择（中文/英文）
   - 启动后行为：保持/最小化/关闭
   - 主题切换：深色/浅色

7. **游戏启动**
   - 启动按钮 + 快速实例切换下拉菜单
   - 运行中状态反馈
   - 启动后行为自动执行
   - 游戏结束恢复窗口

8. **测试支持**
   - 自动检测 D:\Game\KSP 并添加为测试实例

### 技术细节
- QDir/QFileInfo 跨平台路径处理
- 信号槽解耦模块通信
- 配置变更自动保存
- QSS动态主题切换无需重启
