# 功能更新记录

## 2026-09-19 自更新源可选「官方 / 镜像」

**需求**：检查更新与更新下载提供官方源和镜像源两种选择。官方源行为不变；镜像源读取博客发布的 release 索引，用 GitHub 镜像加速直链下载。

**启动器改动**：
- `ConfigManager` 新增 `updateSource` 配置项（`Official=0` 默认 / `Mirror=1`），持久化于 `HKSPL.json` 的 `updateSource` 字段。全局生效：手动检查和开机自动检查都跟随所选源。
- `UpdaterManager`：
  - `checkForUpdate()` 按所选源分流：官方源走原 `https://api.github.com/.../releases/latest`（行为不变）；镜像源请求 `https://zwqbook.cn/api/release/index.json`，经新增 `parseMirrorIndex()` 解析 `{version, zip_url, zip_backup_url, notes_url, sha256}`。
  - 新增 `beginDownloadAt()`：下载支持主备 zip 直链回退（网络失败或 SHA256 校验不符时自动切换备用链，全部用尽才报错）。
- 更新弹窗（`updateflow.cpp`）：镜像源无内嵌发布日志，改为显示「查看发布日志」按钮，点开浏览器访问 `notes_url`（博客站内文章）。
- 设置页（`settingspage.cpp`）「通用设置」新增「更新源」下拉（官方源 GitHub / 镜像源博客加速）。

**Blog（server）新增 release 模块**：
- Prisma 新增 `Release` 模型（version/sha256/zip_url/zip_backup_url/notes_url/postId/isCurrent…），并通过 `Release[]` 关联 `Post`。
- 管理端单接口一键发布 `POST /api/release`（admin JWT）：提交 `version + sha256 + zip_url + zip_backup_url`，可选上传 `RELEASE_NOTES.md`（multipart 文件字段 `notes`）——上传则自动发布为一篇站内文章并回填 `notes_url`，同时把该版本设为当前索引。
- 公开索引 `GET /api/release/index.json` 供启动器读取。

**镜像索引 JSON 规范**（两端一致）：
```json
{
  "version": "1.2.3",
  "zip_url": "https://ghfast.top/https://github.com/Zhuwenqian/Hello-KSP-Launcher/releases/download/v1.2.3/Hello-KSP-Launcher-x86_64-1.2.3.zip",
  "zip_backup_url": "https://gh-proxy.com/https://github.com/<同上资产>",
  "notes_url": "https://zwqbook.cn/posts/hkspl-release-1-2-3",
  "sha256": "<64 位小写 hex>"
}
```

> 完整部署/使用说明见 `readme/更新源镜像部署交接.md`。
